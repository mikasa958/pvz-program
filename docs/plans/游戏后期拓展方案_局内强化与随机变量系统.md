# 游戏后期拓展方案：局内强化与随机变量系统设计大纲

## 一、后期拓展定位

当前游戏已经具备基础塔防闭环，包括：

- 网格地图
- 防御塔放置
- 敌人移动
- 自动攻击
- 资源增长
- 基地血量
- 胜负判定

但当前环境仍然偏向“最小可运行塔防原型”，存在以下不足：

1. 游戏机制较简单，和经典 PVZ 类塔防游戏差距较大。
2. 玩家策略单一，主要是“有资源就放塔”。
3. 敌人和地图变化不足，局内决策深度不够。
4. AI 面对的环境较固定，难以体现智能决策价值。

因此，后续拓展方向确定为：

> **以局内强化为主线，引入随机变量、随机波次、地图变化和临时强化，使游戏从简单塔防原型升级为“类 PVZ + 局内 Roguelike 强化”的动态策略塔防环境。**

---

## 二、总体设计目标

### 2.1 核心目标

后续版本的目标不是完整复刻 PVZ，而是在现有 Python 塔防游戏基础上，提取 PVZ 的核心策略体验，并结合局内随机强化机制，增强游戏深度。

主要目标如下：

1. **提升 PVZ 相似度**  
   引入植物类型、阳光资源、敌人波次、卡牌冷却、僵尸差异化等机制。

2. **增强局内成长感**  
   每通过一波敌人后，玩家可以获得随机强化，使单局游戏形成不同发展路线。

3. **增加随机变量**  
   每局游戏的敌人组合、地图格子、波次词条和资源条件存在变化，提高可玩性。

4. **增强 AI 决策价值**  
   AI 不再面对固定环境，而是需要根据随机变量、强化状态和敌人压力动态调整策略。

---

## 三、玩法总流程

后续版本建议采用如下流程：

```text
游戏开始
  ↓
生成本局随机变量
  ↓
进入第 1 波敌人
  ↓
玩家放置植物 / 防御塔进行防守
  ↓
击退当前波次
  ↓
出现局内强化三选一
  ↓
玩家选择一个强化
  ↓
进入下一波敌人
  ↓
敌人增强 / 地图变化 / 随机事件触发
  ↓
重复循环
  ↓
通关或失败
```

该流程的核心是：

> **每一波结束后，玩家都能获得一次成长选择；每一局游戏都存在不同随机变量。**

## 四、核心系统一：局内强化系统

局内强化系统是本次拓展的核心。

### 4.1 强化触发时机

建议设置三种触发方式：

| 触发方式 | 说明 | 推荐程度 |
|---|---|---|
| 每通过一波敌人后触发 | 稳定、清晰、容易实现 | 必做 |
| 击杀一定数量敌人后触发 | 增加正反馈 | 可选 |
| 随机事件触发强化 | 增加不确定性 | 后期扩展 |

第一版推荐实现：

> **每通过一波敌人后，系统随机生成 3 个强化选项，玩家选择其中 1 个。**

---

### 4.2 强化选择方式

每波结束后弹出强化选择界面：

```text
第 2 波结束

请选择一个强化：

[ 火力增强 ]
所有攻击植物伤害 +20%

[ 阳光增产 ]
向日葵产阳光 +20%

[ 坚固根系 ]
所有植物生命值 +20%
```

玩家点击一个强化后，该强化立即生效，并进入下一波。

---

### 4.3 强化分类设计

局内强化分为五类：

1. 攻击类强化
2. 防御类强化
3. 经济类强化
4. 控制类强化
5. 特殊机制强化

---

## 十一、核心系统二：随机变量系统

随机变量系统用于保证每一局游戏不同。

建议将随机变量分为四类：

1. 开局随机变量
2. 波次随机变量
3. 地图随机变量
4. 随机事件变量

---

## 十二、开局随机变量

开局随机变量在游戏开始时生成，影响整局游戏。

### 12.1 随机初始资源

| 模式 | 初始阳光 | 说明 |
|---|---:|---|
| 极限开局 | 50 | 前期压力大 |
| 资源紧张 | 75 | 需要谨慎布局 |
| 普通开局 | 100 | 标准模式 |
| 富裕开局 | 150 | 前期更容易展开 |

---

### 12.2 随机可用植物

不是每局都提供全部植物，而是随机抽取部分植物进入本局。

示例：

```text
本局可用植物：
豌豆射手、向日葵、坚果墙、寒冰射手
```

下一局可能变为：

```text
本局可用植物：
豌豆射手、双发射手、炸弹植物、减速植物
```

这样可以增加阵容变化。

---

### 12.3 随机本局词条

| 本局词条 | 效果 |
|---|---|
| 阳光充足 | 初始阳光 +50 |
| 资源紧张 | 初始阳光 -25 |
| 高压模式 | 敌人数量 +20% |
| 植物脆弱 | 植物生命值 -10% |
| 敌人狂暴 | 敌人速度 +10% |
| 经济困难 | 阳光产出 -15% |

第一版推荐实现：

1. 阳光充足
2. 资源紧张
3. 高压模式
4. 植物脆弱

## 十四、地图随机变量

地图随机变量用于改变网格环境，使地图不再固定。

### 14.1 随机障碍格

开局随机生成若干不能种植的格子。

示例：

```text
第 2 行第 4 列：障碍格
第 4 行第 6 列：障碍格
```

作用：

1. 限制玩家布局；
2. 增加 AI 判断难度；
3. 提高每局差异性。

---

### 14.2 随机强化格

| 格子类型 | 效果 |
|---|---|
| 攻击高地 | 种植攻击植物时伤害 +15% |
| 肥沃土地 | 种植向日葵时阳光产量 +20% |
| 坚硬土地 | 种植防御植物时生命值 +20% |
| 冰霜格 | 该行敌人速度降低 |
| 危险格 | 植物生命值降低，但攻击提升 |

第一版推荐实现：

1. 障碍格
2. 攻击高地
3. 肥沃土地

### 17.4 游戏数值修正器

建议使用统一的 `game_modifiers` 管理当前局内强化效果。

```python
game_modifiers = {
    "plant_damage_multiplier": 1.0,
    "plant_hp_multiplier": 1.0,
    "sun_produce_multiplier": 1.0,
    "plant_cost_multiplier": 1.0,
    "cooldown_multiplier": 1.0,
    "enemy_speed_multiplier": 1.0,
    "enemy_hp_multiplier": 1.0,
    "kill_sun_bonus": 0
}
```

强化生效时，只修改对应倍率：

```python
game_modifiers["plant_damage_multiplier"] += 0.2
```

这样做的好处是：

1. 不需要到处修改实体属性；
2. 方便 AI 读取当前强化状态；
3. 方便保存和调试；

## 二十二、答辩表述建议

可以在汇报中这样说明：

> 当前版本已经实现了塔防游戏的基础闭环，包括网格地图、防御单位放置、敌人移动、自动攻击、资源增长和胜负判定。但从策略深度来看，当前环境仍然偏向最小化原型，游戏规则较固定，玩家的决策空间较小。  
>
> 因此，后续拓展方向将以“局内强化”和“随机变量”为核心。具体来说，游戏将在每一波敌人结束后提供随机强化选项，玩家可以从攻击、防御、经济等方向中选择一种强化，使单局游戏形成不同的发展路线。同时，系统会在开局、波次和地图层面引入随机变量，例如敌人速度提升、敌人血量提升、障碍格、强化格等，使每一局游戏环境都产生差异。  
>
> 这种设计一方面可以增强游戏的可玩性，使其更接近 PVZ 类策略塔防游戏；另一方面也可以提高 AI 决策环境的复杂度，使智能体需要根据动态变化的局势进行策略调整，从而更好地支撑“智能化辅助功能研究”的项目主题。

## 二十五、结论
