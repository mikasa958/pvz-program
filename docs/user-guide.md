# 《PVZ Roguelike Defense》游戏说明书

一款用 Python 编写的**类植物大战僵尸塔防 + Roguelike 三选一强化**小游戏。在格子上种植物、收集阳光、抵御多波僵尸，并在大本营血量耗尽前撑到最后。

---

## 一、如何开始游戏

### 方式 A：直接运行 exe

1. 运行打包后的 **`dist\TowerDefense.exe`**（或你收到的 `TowerDefense.exe`）。  
2. **双击**启动。  
3. 若杀毒软件提示，请在确认来源可信后选择信任或加入白名单（单机小游戏偶有误报）。

### 方式 B：用源码运行

1. 在项目目录执行：`pip install -r requirements.txt`  
2. 执行：`python main.py`（或使用虚拟环境：`.venv\Scripts\python.exe main.py`）  
3. 窗口标题类似 **Tower Defense RL Environment**，出现棋盘即成功。

### 重新打包 exe

在仓库根目录的 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

生成的新 exe 位于 **`dist\TowerDefense.exe`**。

**记录文件：** 游戏会在运行目录下创建 **`logs`** 文件夹，用于对局记录（不影响正常游玩）。

## 二、操作说明

| 按键 / 操作 | 作用 |
|-------------|------|
| **鼠标左键** | **MANUAL** 模式：在可种格子上种植**当前选中植物**；可点击**阳光**提前拾取（约 2 秒后也会自动飞入）；强化界面可点击卡片。 |
| **Q** | 选择 **豌豆射手**（远程输出）。 |
| **W** | 选择 **向日葵**（产阳光）。 |
| **E** | 选择 **坚果墙**（高血量阻挡）。 |
| **S** | **铲子**：点击或拖拽格子上植物以铲除；再按 **Q/W/E** 回到种植。 |
| **1 / 2 / 3** | 三选一强化界面选择第 1 / 2 / 3 项。 |
| **F1** | **手动模式** — 自己种植、自己点阳光。 |
| **F2** | **规则 AI** — 程序按规则自动决策。 |
| **F3** | **模型 AI** — 策略接入接口；当前默认策略为等待，需要自行接入训练结果。 |
| **P** | **暂停 / 继续**。 |
| **R** | **重新开始** 一局。 |
| **ESC** | **退出** 游戏。 |

**提示：**

- 使用 **Q/W/E/S** 前，先用鼠标**点击游戏窗口**确保焦点在游戏内。  
- 使用中文输入法时建议切换到**英文**，否则快捷键可能无效。  
- 人类游玩请确认左上角为 **`MODE: MANUAL`**（可按 **F1** 切换）。

## 三、界面说明

- **上方 HUD：** 阳光、基地血量、当前波次 / 总波数、已选强化数量等。  
- **右上小面板：** 当前工具（种植 / 铲子）、植物名称、花费、冷却与就绪状态。  
- **中间棋盘：** 5×9 格战场；部分格子可能有地图效果（以画面为准）。  
- **下方：** 提示信息与局内加成摘要。  
- **强化阶段：** 出现三张强化卡时，用**鼠标点击**或 **1/2/3** 选择。

## 四、常见问题

**Q：按 Q/W/E 没反应？**  
A：先点击游戏窗口；输入法切英文；确认 **F1 手动模式**。

**Q：点格子不种植物？**  
A：可能处于 **F2/F3** AI 模式，或本局已结束（按 **R** 重开）。

**Q：铲子在哪里？**  
A：按 **S** 进入铲子模式，右上会显示 **Shovel**；再按 Q/W/E 回到植物。

**Q：与正版《植物大战僵尸》的关系？**  
A：本作是同人向独立实验作品，玩法灵感类似但程序、数值与内容均为独立设计，与商业原作无关联。
